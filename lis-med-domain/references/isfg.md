# ISFG: что учитывать в расчётах (кратко)

Источник: рекомендации ISFG (International Society for Forensic Genetics) по анализу STR и по мутациям,
публикации в Forensic Science International: Genetics. Точную цитату/год брать из первоисточника
перед использованием в коде или отчёте — не по памяти.

Ключевые положения, которые обычно влияют на код:

1. **Мутации** — при одном несовпадении в локусе нельзя автоматически объявлять исключение: вероятность
   мутации учитывается в модели (paternal/maternal), её частота — параметр, а не константа «на глаз».
2. **Порог числа локусов** — интерпретация при малом числе локусов ограничена; в отчёте указывается,
   сколько локусов реально использовано.
3. **Популяционные частоты** — использовать частоты, соответствующие заявленной популяции; субпопуляция
   фиксируется в результате (у нас поле `SubpopulationId`).
4. **Смеси** — требуется модель вкладов; «просто вычесть» нельзя.
5. **Валидация** — расчёт должен воспроизводиться: версия метода (`MethodCode`), входные данные,
   параметры. У нас это поля снимка результата.

Правило для агента: сомневаешься в конкретной формулировке рекомендации — ищи первоисточник
(PubMed / сайт ISFG) и приводи ссылку в комментарии к коду и в карточке задачи.
