# RAD Studio: установка и активация из раздач (стенд автосборки)

Класс задач: развернуть RAD Studio на чистой ВМ стенда и активировать (в т.ч. для автосборки).
Лицензионные условия CI, silent install и питфолл trial-компилятора — в `references/rad-studio-ci-licensing.md`.

## Где лежат дистрибутивы и «кряк»

- В раздачах RuTracker (редакция Architect) **KeyPatch лежит РЯДОМ С ДИСТРИБУТИВОМ** — отдельно искать не надо:
  внутри торрента `*KeyPatch.rar`/`*KeyPatch.zip` + одноимённый `*KeyPatch.txt` (пароль к архиву).
  Проверять листингом файлов раздачи (qB: `GET /api/v2/torrents/files?hash=…`, либо папка после скачивания).
- Собранный комплект: `/soft/Delphi/RADStudio/_АКТИВАЦИЯ/` — KeyPatch для 10.3.3–13.2 + пароли `.txt` +
  тексты инструкций из раздач (`instrukcia_10.4.txt`, `instrukcia_13.x.txt`) + `README_AKTIVACIA.md`.
  Использовать его, а не перечитывать раздачи; пополнять при новых версиях.
- Описания раздач содержат спойлеры «Как патчить», «Пароль от КейПатча», «Блокируемые сервера»; в HTML они
  уже раскрыты (`.sp-wrap/.sp-head/.sp-body`) — доступ к страницам рутрекера через CF-солвер
  (раздел «Чтение страниц» в `qbittorrent-management`).

## Процедура (из инструкций раздач)

1. Ставить на ЧИСТУЮ ВМ (требование раздач).
2. До студии: Java JRE + JDK и Windows SDK, перезагрузка (инсталляторы есть в раздачах/дистрибутиве).
3. Windows Defender на время установки и патча ОТКЛЮЧИТЬ + исключения на папки — ругается на KeyPatch.
4. KeyPatch запустить ДО установки и заблокировать сервера активации: правый клик в окне KeyPatch →
   «Block servers in the hosts file» (ручной список — в спойлере «Блокируемые сервера» раздачи).
5. Смонтировать ISO → установщик от Администратора → дойти до страницы «Ввод лицензии» и НЕ нажимать
   «Install» → в KeyPatch «PATCH» → в установщике «Back» → «Use Existing License» → продолжить установку.
6. После установки проверить CLI-сборку тестового проекта (питфолл trial-компилятора — в
   `references/rad-studio-ci-licensing.md`).

## Состав установки стенда

- Только Delphi, без C++Builder.
- Платформы: Windows 32-bit + 64-bit, Linux 64-bit; мобильная разработка (Android/iOS) не ставится.
- Диск стенда — с расчётом на ЧЕТЫРЕ версии IDE: 10.3.3 (рабочий проект МГ), 10.4, 12, 13.
- Установку IDE BOSS может захотеть запустить сам — позвать его; применение KeyPatch согласовано за агентами.
- Инсталляторы всех версий — в `/soft/Delphi/RADStudio/` (10.3.3 … 13.2; там же C++Builder 10.4).
